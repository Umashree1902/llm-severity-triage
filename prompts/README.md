# Prompt templates

Versioned prompt templates for conditions P0 (text only), P1 (with context) and P2 (guardrailed: Mozilla severity definitions plus a confidence value for deferral).

For RQ2b, P1 has two reworded versions (`reworded_1`, `reworded_2`) that keep the same instructions and inputs but change the wording. The optional retrieval extension adds similar past defects to P2.
